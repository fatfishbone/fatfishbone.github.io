[The Maze game!]

This is an online game that uses AI and runs entirely on HTML.

⚠ATTENTION☢
This game is in [Alpha Test]!
There might be some critical bugs!

:Game Description:
Avoid obstacles, collect orbs, solve puzzles, and make your way to the goal!

Move=WASD or Drag screen
Pov=Mouse or Drag screen
Use Weapons =Click or Tap screen
Interact=E key or Tap Screen
Portal weapon : Blue=Left click Orange=Right click or Blue=Tap Screen Orange=Tap screen with two fingers
